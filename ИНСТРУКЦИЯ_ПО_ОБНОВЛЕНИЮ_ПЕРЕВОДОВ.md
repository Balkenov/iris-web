# Инструкция по обновлению переводов в проекте IRIS

## Обзор

Данная инструкция описывает процесс обновления переводов в проекте IRIS путем модификации файлов сообщений (messages files). Проект использует систему интернационализации на основе Flask-Babel.

## Структура файлов переводов

Переводы в проекте организованы следующим образом:

```
source/app/
├── messages.pot                    # Шаблон переводов (template)
├── babel.cfg                       # Конфигурация Babel
└── translations/                   # Директория с переводами
    ├── ru/                         # Русский язык
    │   └── LC_MESSAGES/
    │       ├── messages.po         # Файл переводов (текстовый)
    │       └── messages.mo         # Скомпилированный файл переводов
    └── kk/                         # Казахский язык
        └── LC_MESSAGES/
            ├── messages.po         # Файл переводов (текстовый)
            └── messages.mo         # Скомпилированный файл переводов
```

## Установка pybabel

Перед началом работы с переводами необходимо установить pybabel:

### Установка через pip

```bash
# Установка pybabel
pip install Flask-Babel

```

### Установка в виртуальном окружении (рекомендуется)

```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
# На Linux/macOS:
source venv/bin/activate

# Установка Flask-Babel
pip install Flask-Babel
```

### Проверка установки

```bash
# Проверить версию pybabel
pybabel --version
```

## Процесс обновления переводов

### 1. Редактирование файлов переводов

Откройте файл `source/app/translations/[язык]/LC_MESSAGES/messages.po` в текстовом редакторе.

#### Структура записи перевода:

```po
#: blueprints/activities/templates/activities.html:20
#: blueprints/alerts/templates/alerts.html:76
msgid "Refresh"
msgstr "Обновить"
```

Где:
- `#:` - комментарии с указанием местоположения строки в коде
- `msgid` - оригинальная строка на английском языке
- `msgstr` - переведенная строка

### 2. Компиляция переводов

После редактирования файлов `.po` необходимо скомпилировать их в бинарный формат `.mo`:

```bash
# Скомпилировать русский перевод
pybabel compile -d translations -l ru

# Скомпилировать казахский перевод
pybabel compile -d translations -l kk
```

### 3. Перезапуск приложения

После компиляции переводов необходимо перезапустить приложение для применения изменений:

```bash
# Перезапуск приложения с пересборкой
docker compose -f docker-compose.dev.yaml up -d --build --force-recreate app
```

## Важные замечания

### Контекст перевода

- Обращайте внимание на комментарии `#:` - они показывают, где используется строка
- Учитывайте контекст использования при выборе перевода
- Для технических терминов используйте единообразные переводы

### Проверка качества

После обновления переводов рекомендуется:

1. Запустить приложение и проверить интерфейс
2. Убедиться, что все строки отображаются корректно
3. Проверить, что форматирование сохранено
4. Протестировать функциональность на переведенном языке

## Заключение

Следуя данной инструкции, вы сможете эффективно обновлять переводы в проекте IRIS, модифицируя только файлы сообщений без изменения основного кода приложения. Помните о важности сохранения контекста и качества переводов для обеспечения лучшего пользовательского опыта.
